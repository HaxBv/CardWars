# Bitacoras — CardWars

Directorio para bitácoras diarias de desarrollo.

Cada bitácora tiene el formato: `Vault/Bitacoras/YYYY-MM-DD.md`

Contiene el registro de una sesión de trabajo completa, desde el inicio hasta el cierre, incluyendo:
- Objetivos de la sesión
- Trabajo realizado
- Archivos modificados
- Problemas encontrados y soluciones
- Decisiones tomadas
- Estado al cerrar sesión

Para crear una nueva bitácora, copie el formato de un archivo existente o use la estructura definida en la documentación principal.
